# Como liberar o instalador do EVR Deluxe no macOS

Se ao abrir o arquivo `EVR-Deluxe-Installer.pkg` aparecer a mensagem:

```txt
O item não foi aberto. A Apple não pode verificar se ele está livre de malware.
```

siga os passos abaixo.

## Passo a passo

1. Clique em **OK** ou feche o aviso.

2. Abra os **Ajustes do Sistema** do Mac.

3. No menu lateral, clique em **Privacidade e Segurança**.

4. Role a tela até encontrar a seção **Segurança**.

5. Procure uma mensagem parecida com:

```txt
EVR-Deluxe-Installer.pkg foi bloqueado para proteger o Mac.
```

6. Clique em **Abrir Mesmo Assim**.

7. O macOS pode pedir a senha do usuário do Mac ou o Touch ID. Confirme.

8. Volte ao arquivo `EVR-Deluxe-Installer.pkg`.

9. Abra o arquivo novamente com dois cliques.

10. Quando o aviso aparecer de novo, clique em **Abrir**.

11. Siga as etapas do instalador normalmente.

12. Depois de instalar, abra **EVR Deluxe** pela pasta **Aplicativos**.

## Observação

Esse aviso aparece porque esta é uma versão interna de teste e ainda não foi assinada/notarizada pela Apple.

O EVR Deluxe é uma ferramenta interna. Se você recebeu o arquivo pelo link oficial da equipe, pode seguir este procedimento para liberar a instalação.
