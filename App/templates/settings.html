Detalhes técnicos

Modo de desempenho

Informações somente leitura sobre como o EVR Deluxe executa os processos neste modo.

    Ajuda rápida

    Configurar APIs

    Passo a passo resumido para conectar as ferramentas de inteligência artificial.

    OpenAI Necessária para revisar transcrições, consultar o glossário e gerar sugestões de cortes e ganchos.
    1. Acesse sua conta na plataforma da OpenAI.
    2. Abra a área de API Keys e crie uma nova chave secreta.
    3. Copie a chave, selecione OpenAI como IA principal, cole no campo de API Key e salve.
    4. Clique em Testar IA principal para confirmar se está tudo OK.

    A API da OpenAI é paga conforme uso e cobrança da sua própria conta OpenAI.

    Abrir API Keys da OpenAI
    Claude Integração experimental para as etapas em que o EVR Deluxe conversa com a IA.
    1. Acesse o console da Anthropic.
    2. Crie ou copie uma API Key ativa.
    3. Selecione Claude como IA principal, cole a chave, escolha o modelo e salve.
    4. Clique em Testar IA principal antes de processar projetos reais.

    A API da Anthropic/Claude é paga conforme as regras da sua conta. Se a chave e o modelo estiverem corretos e der erro, reporte para Robson Yuri.

    Abrir API Keys da Anthropic
    Gemini Integração experimental para revisão automática e sugestões de cortes.
    1. Acesse o Google AI Studio.
    2. Crie uma API Key para Gemini.
    3. Selecione Gemini como IA principal, cole a chave, escolha o modelo e salve.
    4. Clique em Testar IA principal antes de usar em um episódio completo.

    Pode haver cobrança conforme a conta Google/modelo. Se a chave e o modelo estiverem corretos e der erro, reporte para Robson Yuri.

    Abrir API Keys do Gemini
    DeepSeek Integração experimental compatível com API em formato parecido com OpenAI.
    1. Acesse a plataforma da DeepSeek.
    2. Crie ou copie uma API Key ativa.
    3. Selecione DeepSeek como IA principal, cole a chave, escolha o modelo e salve.
    4. Clique em Testar IA principal para validar antes de processar.

    A API pode ser paga conforme a sua conta DeepSeek. Se a chave e o modelo estiverem corretos e der erro, reporte para Robson Yuri.

    Abrir API Keys da DeepSeek
    Hugging Face / Pyannote Opcional para mapear participantes e identificar quem fala em cada trecho do vídeo.
    1. Crie ou acesse sua conta na Hugging Face.
    2. Abra Settings, depois Access Tokens, e crie um token de acesso.
    3. Confirme acesso ao modelo Pyannote usado pelo EVR Deluxe, quando a Hugging Face solicitar.
    4. Copie o token, cole no campo Hugging Face Token, salve e clique em Testar Hugging Face para liberar a etapa opcional de participantes.

    Alguns modelos da Pyannote exigem aceite de termos na página do modelo antes do token funcionar.
